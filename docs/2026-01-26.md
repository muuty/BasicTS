### 5. Experience Replay 상세 분석
- **시간**: 16:00 (AEST)
- **분석 스크립트**: `scripts/visualization/analyze_experience_replay.py`

#### Experience Replay 종합 비교

| Config | MAE | Non-Inc MAE | Inc MAE |
|--------|-----|-------------|---------|
| STAEformer Baseline | **11.76** | 11.53 | 12.67 |
| STGformer Baseline | 11.79 | 11.57 | 12.68 |
| STAEformer + Difficult (w=0.1) | 11.87 | 11.64 | 12.78 |
| STGCN + Random Replay (w=0.1) | 13.84 | 13.57 | 14.93 |
| STGCN Baseline | 17.91 | 17.63 | 19.01 |

#### 핵심 결론

1. **STGCN에서 Experience Replay 매우 효과적**
   - MAE 17.91 → 13.84 (**-22.7% 개선**)
   - Random sampling + weight=0.05~0.1 최적
   - weight 너무 크면 성능 저하

2. **STAEformer/STGformer에서는 Replay 효과 없음**
   - 이미 baseline 성능 우수 (MAE ~11.76)
   - Replay 추가 시 오히려 소폭 성능 저하

3. **Sampling Method 비교**
   - Random > Representative (STGCN 기준)

4. **추천 설정**
   - STGCN: Random replay, weight=0.05~0.1, batch=64, capacity=0.1
   - STAEformer/STGformer: Replay 없이 baseline 사용
