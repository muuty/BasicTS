오늘의 Daily Review를 작성해줘.

## 수행 절차

1. **오늘의 작업 파악**: 다음을 확인하여 오늘 무엇을 했는지 파악한다.
   - `git log --since="today" --oneline` 으로 오늘의 커밋 확인
   - `git diff --stat` 으로 현재 변경사항 확인
   - `squeue -u $USER` 으로 실행 중인 SLURM job 확인
   - `docs/TASK.md`의 현재 상태 확인
   - 오늘 대화에서 수행한 작업 내용 참조

2. **리뷰 작성**: 아래 형식으로 `docs/DAILY_REVIEW.md`에 오늘 날짜 섹션을 추가한다.

```markdown
## YYYY-MM-DD

### 오늘 한 일
- (구체적 작업 내역)

### 진전된 것
- (어제보다 나아진 점, 해결된 문제)

### 막힌 것 / 아쉬운 것
- (해결 못한 문제, 시간 낭비, 실수)

### 배운 것
- (새로 알게 된 기술적 사실, insight)

### 내일 할 것
- (다음 작업 우선순위)
```

3. **IDEAS 업데이트**: 오늘 작업 중 떠오른 아이디어가 있으면 `docs/IDEAS.md`에도 추가한다.

4. **TASK 업데이트**: `docs/TASK.md`의 작업 상태를 최신으로 업데이트한다.

## 주의사항
- 리뷰를 작성한 후 사용자에게 보여주고 검토를 요청한다.
- 사용자가 수정/승인한 후에만 최종 저장한다.
- 간결하게 작성한다. 각 항목 1~3줄이면 충분하다.
